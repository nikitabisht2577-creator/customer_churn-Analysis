Customer Churn Analysis

Project Overview
Customer Churn Analysis is a data analytics project focused on analyzing customer behavior and identifying patterns related to customer churn.
The project used Python, MySQL, and Power BI to clean, analyze, and visualize customer data to generate meaningful business insights.

Project Objectives
• Analyze customer data and behavior.
• Identify customer churn patterns.
• Explore customer demographics and service usage.
• Analyze monthly charge and payment methods.
• Create an interactive Power BI Dashboard.
• Generate actionable business insights and recommendations.

Tools & Technologies
• Python - Data Cleaning and Data Analysis.
• Pandas & NumPy - Data Manipulation.
• MySQL - Database Management and SQL Analysis.
• Power BI - Interactive Dashboard and Visualization.
